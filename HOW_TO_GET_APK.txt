CITY FREEDOM MAKKAH - V12 (Godot 3.6, GLES2, for older Android TVs)
1. Upload ALL files of this folder to your GitHub repository (including the hidden .github folder).
   If .github is missing, create the file .github/workflows/build-apk.yml by hand and paste the workflow.
2. Actions > "Build Android APK (Godot 3.6 GLES2...)" > Run workflow.
3. Download "CityFreedom-Makkah-apk" > unzip > CityFreedom-Makkah.apk > install on the TV.
4. If it fails, open the red step and send me the text (also the "smoke-test-log" artifact).
Controls: UP/DOWN move, LEFT/RIGHT turn, OK/ENTER or gamepad A = car, H / X = horn, C / Y = camera,
B = clothes, M = map, N = night, Z = azan. Gamepad works. Remote BACK closes the map/clothes.
AZAN: put a WAV recording (16-bit) at data/azan.dat before building.
To change the map: replace map.osm and run tools/osm2city.py (needs Python), it writes data/city.json.
